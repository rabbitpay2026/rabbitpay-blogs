  To create a new RabbitPay blog post:

  1. Duplicate this template.
  2. Save the new article under `posts/` using a descriptive lowercase URL slug, for example: `posts/reduce-rto-shopify.md`.
  3. Update the `title` and `description` in the frontmatter.
  4. Replace the category, author, publication date, reading time, and cover image below.
  5. Write and edit the article using Mintlify's visual editor.
  6. Add the new page to the Blog navigation in `docs.json` when it is ready to publish.
  7. Preview the article before publishing.

  Remove this entire note before the article goes live.
</Note>
